# Frontend Migration Reference & Domain Knowledge Specification

This document preserves the complete product behavior, UI interactions, schema definitions, form validation rules, and domain logic from the retired React + Inertia frontend. This reference serves as the blueprint for recreating the frontend in Next.js.

---

## 1. Design System & Theme Foundation

### Color Palette & Tokens
* **Background Dark**: `#020817` (Deep slate/black canvas)
* **Navy / Surface**: `#07111F` / `#0B1424` (Card backgrounds, sidebar, search modal)
* **Elevated / Hover**: `#0E192B` / `#1E293B` (Borders, active states, hover surfaces)
* **Brand Cyan / Accent**: `#19C6E8` (Primary interactive accents, highlight text, badges)
* **Brand Blue**: `#3B82F6` (Gradients, secondary highlights)
* **Text Primary**: `#F8FAFC` (Headings, primary body text)
* **Text Muted / Subdued**: `#94A3B8` / `#64748B` (Excerpts, timestamps, metadata labels)
* **Status Badges**:
  * Published: `bg-emerald-500/10 text-emerald-400 border border-emerald-500/20`
  * Draft: `bg-amber-500/10 text-amber-400 border border-amber-500/20`
  * Scheduled: `bg-blue-500/10 text-blue-400 border border-blue-500/20`

### Typography & Fonts
* **Primary Sans**: `Plus Jakarta Sans` or `Inter`, sans-serif
* **Monospace / Technical Accent**: `JetBrains Mono` / `Fira Code` (Used for CAD badges, metadata tags, sidebar labels, dates, read times)

## 2. Navigation & Dynamic Menu Builder

### Architecture & Data Structure
The menu builder supports recursive multi-level trees (e.g. Header Menu, Footer Menu).

```typescript
interface MenuItem {
  id?: number | string;
  parent_id?: number | null;
  title: string;
  url?: string | null;           // When link_type === 'url'
  route?: string | null;         // When link_type === 'route' (named Laravel route)
  route_params?: Record<string, any> | string | null;
  new_tab: boolean;
  icon?: string | null;          // Lucide icon identifier
  color?: string | null;         // Custom text color hex
  bg_color?: string | null;      // Custom background color hex
  css_class?: string | null;
  order: number;
  is_active: boolean;
  children?: MenuItem[];
}

interface MenuData {
  id: number;
  name: string;
  items: MenuItem[];
}
```

### Menu Builder UI Interactions
1. **Tree Management**:
   * Add top-level item with Title, Link Type (`url` or `route`), target URL/Route, Target Window (`new_tab`), Icon, and Styling.
   * Add nested sub-item via "Add Sub-item" (`handleAddChild`).
   * Reorder items up/down at the current nesting level (`moveItem`).
   * Nested level indentation: `ml-6 pl-4 border-l-2 border-indigo-500/20`.
   * Delete item recursively (removes parent and all associated children).
2. **Settings Drawer/Accordion**:
   * Toggle settings accordion per item (`Settings2` icon).
   * Live preview of title and target URL / route badge.
3. **Menu Cache Invalidation**:
   * Saving a menu clears cache keys: `header_menu_tree`, `footer_menu_tree`, `menu_tree_header-menu`, `menu_tree_footer-menu`.

## 3. Blog & Editorial Management

### Article Schema & Fields
| Field | Type | Rules / Behavior |
|---|---|---|
| `title` | string (max 255) | Required. Triggers automatic slug generation if slug is empty. |
| `slug` | string | Auto-generated via Spatie Sluggable from title; unique. |
| `category_id` | unsigned bigInt | Required. Belongs to `Category`. |
| `tags` | array of IDs | Optional many-to-many relationship synced via `tags()`. |
| `excerpt` | text (nullable) | Short summary for cards and search results. |
| `content` | longText (HTML) | Rich text HTML generated by TipTap editor. |
| `featured_image` | string (nullable)| Path or URL to article cover image. |
| `status` | enum | `draft`, `published`, `scheduled`. |
| `is_featured` | boolean | Promotes article to the Main Hero feature spot. |
| `is_engineering_spotlight` | boolean | Highlights article in the "Engineering Spotlight" section. |
| `read_time_minutes` | integer (min 1) | Estimated reading duration in minutes (defaults to 8). |
| `published_at` | datetime (nullable)| Automatically set to `now()` when status transitions to `published` if null. |
| `scheduled_at` | datetime (nullable)| Publication target for scheduled articles. |
| `seo_title` | string (nullable)| Custom `<title>` meta override. |
| `meta_description` | text (nullable) | Custom `<meta name="description">` override. |
| `canonical_url` | string (nullable)| Custom canonical URL override. |
| `view_count` | integer | Incremented once per session per article visit. |

### TipTap Rich Text Editor Configuration
* **Extensions**:
  * `StarterKit` (Headings 1-2, Bold, Italic, BulletList, OrderedList, Blockquote, Undo, Redo)
  * `LinkExtension` (`openOnClick: false`)
  * `ImageExtension` (Prompt for image URL and insert into prose flow)
* **Styling**: `prose prose-invert max-w-none min-h-[250px] p-4 text-slate-100 focus:outline-none text-sm leading-relaxed`.

## 4. Public Web Presentation & Features

### 1. Editorial Homepage Layout
* **Hero Section**:
  * Left: Technical publication title ("UNDERSTANDING AIRCRAFT BEYOND THE SURFACE"), badge `// ENGINEERING • AVIATION • AIRFRAME`, primary CTA to `/articles`.
  * Right: Interactive/dramatic aircraft cutaway visual (`/public/assets/img/aviation/hero-aircraft-cutaway.png`) with CAD HUD coordinate tags (`[STA 240.0]`, `[WL 100.0]`, `[BL 0.0]`).
  * GSAP entrance animation on load (gracefully skipped if `prefers-reduced-motion: reduce`).
* **Featured & Spotlight Sections**:
  * Hero Featured Article Card with category badge, read time, and view count.
  * Engineering Spotlight component featuring detailed schematic breakdown.
* **Latest & Popular Articles**:
  * 6 latest published articles in a 3-column responsive grid.
  * 3 most-viewed articles in a ranked sidebar/grid.
* **Categories Showcase**:
  * Cards showing icon, name, description, and `published_articles_count`.
* **Newsletter Subscription**:
  * Email capture with `Subscriber::firstOrCreate(...)` into `subscribers` table.

### 2. Article Reading Experience
* **Reading Progress Bar**: Fixed top progress bar (`width: scrollPercent%`).
* **Table of Contents**: Dynamically parsed from `<h2>` and `<h3>` heading anchors within `content`.
* **Social Share**: One-click sharing for Twitter/X, LinkedIn, Facebook, and Copy Link.
* **Related Articles**: 3 articles from the same category (excluding current article).
* **Ad Slot Banner**: Conditionally rendered when `ads_enabled === true` (from `settings` table).

### 3. Live Search & Modal
* **Modal Shortcut**: Triggered by `Cmd+K` / `Ctrl+K` or clicking search icon.
* **Endpoint**: `GET /search?q={query}` returning JSON list of matching articles (`id`, `title`, `slug`, `excerpt`, `category`, `published_at`, `read_time_minutes`).

## 5. SEO & Structured Data Requirements

* **Schema.org JSON-LD**:
  * Articles render `BlogPosting` with `headline`, `description`, `image`, `datePublished`, `dateModified`, `author` (Organization: Aircraft Airframe Editorial Team), and `publisher` (with logo).
  * Category and About pages render `WebPage`.
* **OpenGraph & Twitter Cards**:
  * `og:site_name`, `og:type` (`article`), `og:title`, `og:description`, `og:image`, `og:url`.
  * `twitter:card` (`summary_large_image`), `twitter:title`, `twitter:description`, `twitter:image`.
* **Dynamic Favicon**:
  * Pulled from site settings (`get_setting('site_favicon')` or `/storage/media/favicon.png`).

## 6. Admin Panel & Authentication Behavior

### Access Control
* **Single Admin Login**: `/admin-login` (public registration is restricted/disabled).
* **Authentication Guard**: Laravel `web` session guard with Spatie Roles & Permissions (`admin`, `manager`, `user`).
* **Permissions**:
  * `view dashboard`
  * `manage users`
  * `manage roles`
  * `manage settings`
* **Admin Dashboard Overview**:
  * Metrics: `total_articles`, `published_count`, `draft_count`, `categories_count`, `subscribers_count`.
  * Table of recent 5 articles with quick edit links.
* **Site Settings Management**:
  * Global `ads_enabled` boolean switch.
  * Site branding, logo upload, favicon upload, and site name.
